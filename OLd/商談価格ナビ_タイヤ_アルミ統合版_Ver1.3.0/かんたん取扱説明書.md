# 商談価格ナビ_タイヤ_アルミ統合版 Ver1.3.0 かんたん取扱説明書

## 1. 起動方法

`index.html` を開きます。

iPadで使う場合は、Safariで開いて「ホーム画面に追加」するとアプリのように起動できます。

## 2. 最初に読み込むもの

「管理」タブから価格表を読み込みます。

- タイヤ価格表: `.xlsx` / `.xlsm`
- アルミ価格表: `.xls` / `.xlsx` / `.xlsm`
- 画像DB: `data/wheel_image_master.json`

価格表は以下の4種類を別々に保持できます。

- 夏タイヤ価格表
- 冬タイヤ価格表
- BSアルミ価格表
- 社外アルミ価格表

読み込んだデータはブラウザ内に保存されます。

## 3. タイヤ価格を見る

1. 「タイヤ」タブを開きます。
2. 必要に応じて「検索条件」を開きます。
3. 夏タイヤ、冬タイヤの検索対象を選びます。初期状態は両方ONです。
4. ブランド、商品、インチ、サイズのボタンをタップして検索します。
5. 必要な場合だけ商品名やサイズの入力欄で絞り込みます。
6. 結果カードで1本価格、4本価格を確認します。
7. セット見積に使う商品は「セット見積に選択」を押します。

## 4. アルミホイール価格を見る

1. 「アルミホイール」タブを開きます。
2. 必要に応じて「検索条件」を開きます。
3. BSアルミ、社外アルミの検索対象を選びます。初期状態は両方ONです。
4. メーカー、パターン、インチ、PCD、穴数、カラーのボタンをタップして検索します。
5. 必要な場合だけ入力欄で絞り込みます。
6. 結果カードで卸価格、販売価格、4本合計を確認します。
7. セット見積に使う商品は「セット見積に選択」を押します。

画像が登録されている場合はカードに表示されます。
画像がない場合は「画像なし」と表示されます。

## 5. セット見積を作る

1. タイヤとアルミをそれぞれ選択します。
2. 「セット見積」タブを開きます。
3. 工賃、ナット代、その他費用、値引きは「管理」タブで調整します。
4. 合計金額が大きく表示されます。
5. 「印刷」を押すと、お客様に渡せる簡易見積を印刷できます。

金額を変更すると合計も自動で更新されます。
タイヤとホイールのインチが違う場合は警告が表示され、合計金額は表示されません。
タイヤとアルミを両方選択したセット品では、組替工賃にセット品割引が自動で反映されます。初期値は30%です。

## 6. アルミ画像を登録する

1. アルミ価格表を読み込みます。
2. 「管理」タブの画像管理を開きます。
3. 画像未登録のパターンを確認します。
4. 「画像を登録」を押して画像を選びます。
5. 推奨ファイル名で画像がダウンロードされます。
6. 「画像DBを書き出す」を押します。
7. ダウンロードした画像を `wheel_images` フォルダへ入れます。
8. 書き出した `wheel_image_master.json` を `data` フォルダへ入れます。

次回から検索結果カードに画像が表示されます。

## 7. 画像ファイル名の例

- `TOPRUN M7` → `toprun_m7.jpg`
- `BALMINUM AR12` → `balminum_ar12.jpg`
- `ECO FORME CRS20` → `eco_forme_crs20.jpg`

## 8. 管理でできること

「管理」タブでは以下を変更できます。

- 税率
- 端数処理
- タイヤ加算額
- 標準掛率
- アルミ掛率
- BSアルミ価格表の仕切り欄表示
- インチ別工賃
- セット品 工賃割引率
- セット見積の工賃・ナット代・値引き
- 印刷項目
- データ初期化
- キャッシュ更新

## 9. 困ったとき

価格表が出ない場合:

- 対応形式のファイルか確認してください。
- 別のシート形式の場合、読み取れないことがあります。
- いったん「管理」タブでデータ初期化してから再読み込みしてください。

画像が出ない場合:

- `wheel_image_master.json` の `imageFile` と画像ファイル名が同じか確認してください。
- 画像が `wheel_images` フォルダに入っているか確認してください。
- 画像形式は `jpg` / `jpeg` / `png` / `webp` を使ってください。

ホーム画面追加後に古い表示になる場合:

- 「管理」タブの「キャッシュ更新」を押してください。
