# 商談価格ナビ_タイヤ_アルミ統合版 Ver1.3.0

## 使い方

1. `index.html` をブラウザで開きます。
2. 「管理」から夏タイヤ、冬タイヤ、BSアルミ、社外アルミの価格表を読み込みます。
3. 「タイヤ」「アルミホイール」でボタン選択式の検索を行い、「セット見積に選択」を押します。
4. 「セット見積」で合計金額を確認し、必要に応じて印刷します。
5. 工賃、ナット代、その他費用、値引き、画像DB管理は「管理」で行います。

## Ver1.1.0の主な変更

- タイヤ価格表とアルミ価格表を別々に保持するように修正しました。
- アルミ検索にPCDと穴数検索を追加しました。
- タイヤインチに応じたインチ別工賃を自動反映します。
- タイヤ＋アルミのセット品は組替工賃にセット品割引率を反映します。初期値は30%です。
- 印刷タイトルを「お見積書」に変更しました。
- 印刷項目を管理画面で選択できるようにしました。
- 印刷用レイアウトは見積書部分のみを対象にしました。

## Ver1.2.0の主な変更

- 夏タイヤ、冬タイヤ、BSアルミ、社外アルミの4価格表を別々に保持します。
- タイヤ検索は夏/冬を個別または両方で検索できます。初期状態は両方ONです。
- アルミ検索はBS/社外を個別または両方で検索できます。初期状態は両方ONです。
- 検索結果カードに価格表ラベルを表示します。
- 印刷CSSを見積書部分だけ印刷する設定に再調整しました。

## Ver1.3.0の主な変更

- アルミ掛率の初期値を0.90にしました。
- 定価が取得できるアルミは、定価×アルミ掛率で販売価格を計算します。
- BSアルミ価格表の「55掛」などの仕切り欄表示を読み取り、管理画面だけに表示します。
- BSアルミ価格表から読み込む商品はメーカー名をBSで統一します。

## 画像DB運用

- 画像DB: `data/wheel_image_master.json`
- 画像フォルダ: `wheel_images/`
- ブラウザだけではフォルダへ直接保存できない場合があるため、画像登録後に推奨ファイル名で画像がダウンロードされます。
- ダウンロードした画像を `wheel_images/` に入れ、書き出した `wheel_image_master.json` を `data/` に入れてください。

## 統合方針

- タイヤ価格表解析は既存のタイヤ商談価格ナビ Ver2.6.0 の専用解析ロジックを移植しています。
- アルミ価格表解析は既存アルミホイール価格ナビ同梱のExcel読込ライブラリを使い、TAW形式、BS価格体系表、BSカタログ非掲載品に対応しています。
- データはブラウザ内に保持され、再読み込み後も可能な範囲で復元します。
- PWAとしてホーム画面追加、オフラインキャッシュに対応しています。
